# AINovelist UI 设计规范

## 1. 项目 UI 定位

AINovelist / NovelCraft 是面向长篇小说创作的 AI 写作工作台，不是普通后台管理系统。界面需要支持用户长时间阅读、编辑、整理资料、管理人物关系、维护记忆一致性并与 AI 协作，因此视觉应强调专注、沉浸、低打扰和可靠感。

核心关键词：

- 语言：中文为主体语言，代码标识符、技术 token 和第三方 API 名称可保留英文。
- 视觉：暖黄色、羊皮纸、低饱和、柔和层级。
- 气质：安静、专注、书卷感、创作感。
- 交互：少弹窗、低打扰、状态清晰、可恢复、适合长文本编辑。
- 细节参考：苹果设计的克制留白、圆角统一、轻阴影、明确焦点态和自然动效。

## 2. 设计来源与使用方式

主参考文件：`pen/UI.pen`。

当前 `UI.pen` 已完成预设计与第二轮页面矩阵迭代，包含：

- `00 Tokens / Style Guide`：色彩、字体、间距、圆角、阴影和状态样例。
- `01 Components`：基础按钮、输入、纸面面板、章节树、知识卡、AI 纸条、空状态、加载态、图标覆盖区、图标组件、带图标导航项、状态胶囊、区块标题。
- `02 Screens - MVP / Page Matrix`：按导航横向排列的页面矩阵，同一导航下的不同视图纵向堆叠。
- `03 Screens - Beta / Pro`：后续能力预留页面。
- `04 Flows`：作品创建、章节写作、知识注入、AI 生成、导出、人物关系维护、记忆确认入库、一致性审查等流程。

设计稿约束：`.pen` 文件必须通过 Pencil MCP 工具读取、截图或修改，不要用普通文本工具处理。

规范与代码对应关系：

- 全局设计令牌：`src/renderer/src/styles/main.css`
- 应用骨架：`src/renderer/src/App.vue`
- 首页：`src/renderer/src/views/HomeView.vue`
- 创作工作台：`src/renderer/src/views/WorkspaceView.vue`
- 知识库：`src/renderer/src/views/KnowledgeView.vue`
- AI 生成面板：`src/renderer/src/components/ai/GeneratePanel.vue`

当前真实代码只落地：首页、创作工作台、知识库与 AI 面板；设计稿中的人物与关系、记忆与一致性、AI 导演、导出、设置属于后续页面预留。

## 3. 视觉原则

### 3.1 暖色与羊皮纸

- 背景使用暖米黄，不使用大面积冷白或后台灰。
- 内容容器使用纸面色，允许轻微色差表现层级。
- 不使用厚重纹理、明显噪点或强拟物边框。
- 文字使用深棕黑，避免纯黑造成压迫。
- 高优先级内容使用更干净的纸面，低优先级辅助面板可使用更暖、更浅的底色。

### 3.2 苹果式克制细节

- 用留白、对齐和层级组织信息，而不是用重边框分割。
- 圆角、阴影和动效保持统一，不做复杂装饰。
- 操作反馈明确但不打断写作流。
- 控件状态要有可见差异：默认、悬停、按下、禁用、聚焦、加载中。
- 页面布局应稳定，悬停和状态切换不改变整体尺寸。

### 3.3 长文本优先

- 编辑区应像一张可长期书写的纸，边距充足。
- 正文区域对比度优先于装饰效果。
- 表单、AI 面板、状态提示不能抢夺主编辑区注意力。
- 错误、保存、生成结果提示应清楚但不刺眼。
- 长文本容器要避免裁切；设计稿中文本优先使用固定宽度增长策略。

## 4. 设计令牌

### 4.1 色彩

| Token | 建议值 | 用途 |
| --- | --- | --- |
| `--color-app-bg` | `#f3e6c8` | 应用底色，暖黄色羊皮纸环境 |
| `--color-app-bg-deep` | `#e7d3a8` | 侧栏或页面深层背景 |
| `--color-paper` | `#fff8e8` | 主纸面、卡片、面板 |
| `--color-paper-soft` | `#fbefd2` | 次级纸面、输入框背景 |
| `--color-paper-strong` | `#f5dfad` | 选中、强调背景 |
| `--color-ink` | `#2f2418` | 主文字 |
| `--color-ink-muted` | `#75634b` | 次级文字 |
| `--color-ink-faint` | `#9a8566` | 辅助说明 |
| `--color-accent` | `#a86f2a` | 主按钮、选中、关键动作 |
| `--color-accent-soft` | `#d9a85d` | 悬停、轻强调 |
| `--color-danger` | `#b4533c` | 危险与错误 |
| `--color-success` | `#5f7f4f` | 成功状态 |
| `--color-warning` | `#c49a3c` | 警告与待确认 |
| `--color-info` | `#8a7a66` | 信息说明 |
| `--color-border` | `rgba(99, 71, 36, 0.16)` | 轻边界 |

状态色使用方式：

- 成功：低饱和绿色，适合保存成功、导出完成。
- 警告：金棕或琥珀色，适合待确认、轻微冲突。
- 错误：柔和砖红色，适合保存失败、路径错误。
- 信息：棕灰或浅金色，适合说明、空状态、AI 建议。

### 4.2 字体

默认不引入外部字体依赖，优先系统字体：

```css
font-family: "PingFang SC", "Microsoft YaHei", "Noto Sans CJK SC", system-ui, -apple-system, BlinkMacSystemFont, sans-serif;
```

长文本编辑区可使用更适合阅读的中文系统字体组合：

```css
font-family: "Songti SC", "SimSun", "Noto Serif CJK SC", serif;
```

设计稿工具中若系统中文字体不可用，可使用 `Inter` 作为 Pencil 内部替代字体；落地到代码时仍按上方系统字体栈执行。

### 4.3 字号

| 场景 | 字号 | 行高 |
| --- | --- | --- |
| 应用标题 | 22–26px | 1.25 |
| 页面标题 | 20–24px | 1.3 |
| 区块标题 | 15–17px | 1.4 |
| 正文 | 15–16px | 1.7 |
| 长文本编辑 | 16px | 1.8–1.9 |
| 辅助文本 | 12–13px | 1.5 |
| 按钮文本 | 14px | 1.4 |

### 4.4 间距

使用 4px 基准节奏：

- `4px`：细小间隔。
- `8px`：控件内部或紧密项。
- `12px`：表单项之间。
- `16px`：卡片内边距最小值。
- `18–20px`：侧栏面板内边距。
- `24px`：面板间距。
- `28–32px`：页面大区块间距。

### 4.5 圆角与阴影

| Token | 建议值 | 用途 |
| --- | --- | --- |
| `--radius-small` | `8px` | 小控件 |
| `--radius-medium` | `14px` | 输入框、按钮、列表项 |
| `--radius-panel` | `22px` | 卡片、面板 |
| `--radius-large` | `30px` | 主编辑纸张、大容器 |
| `--shadow-panel` | `0 18px 50px rgba(80, 55, 20, 0.12)` | 主面板、模态框 |
| `--shadow-soft` | `0 8px 26px rgba(80, 55, 20, 0.08)` | 次级面板 |
| `--shadow-raised` | `0 2px 8px rgba(80, 55, 20, 0.06)` | 悬停抬升、按钮按下 |
| `--shadow-floating` | `0 12px 40px rgba(80, 55, 20, 0.10)` | 下拉菜单、浮层、Toast |

### 4.6 动效

| Token | 建议值 | 用途 |
| --- | --- | --- |
| `--duration-fast` | `100ms` | 微交互、按钮按下 |
| `--duration-normal` | `140ms` | 常规过渡、悬停反馈 |
| `--duration-slow` | `220ms` | 面板展开、模态出现 |
| `--easing-standard` | `ease` | 默认缓动 |
| `--easing-decelerate` | `cubic-bezier(0, 0, 0.2, 1)` | 进入动画、元素出现 |
| `--easing-accelerate` | `cubic-bezier(0.4, 0, 1, 1)` | 退出动画、元素消失 |
| `--stagger-gap` | `40ms` | 列表项依次出现间隔 |

- 不使用复杂弹性动效。
- 尊重 `prefers-reduced-motion: reduce`，必要时关闭过渡。
- 保存、生成、导出等长任务应优先使用局部 loading，不遮挡整页。

## 6. 页面规范

### 6.1 首页

首页承担”回到创作”的入口，不应像设置面板。

应包含：

- 简短项目介绍。
- 继续创作 / 进入工作台的主行动入口。
- 最近作品横向卡片列表（封面/标题/最后编辑时间/继续创作入口）。
- 今日写作统计小卡片（字数、时长、连续天数）。
- 本机数据目录状态。
- 温和的空状态或提示语。

视觉建议：大纸面欢迎卡 + 统计卡片 + 最近作品横向滚动 + 路径信息小卡片 + 快捷入口。

### 6.2 创作工作台

工作台采用三栏结构：

- 左侧：作品与章节目录，类似纸签或书签。
- 中间：主编辑纸张，视觉优先级最高。
- 右侧：AI 助手、上下文预览与生成结果，类似批注便签。

要求：

- 保留本地数据闭环：创建作品、创建章节、读取、保存。
- 编辑区应宽敞，正文输入不被面板抢焦点。
- 编辑器顶部预留工具栏视觉（粗体、斜体、标题、引用、预览、全屏），当前以 textarea 实现时可保持占位。
- 保存反馈清晰但不打断：显示"上次保存于 XX:XX"或"自动保存中..."微状态胶囊。
- 显示字数、保存时间、章节状态等辅助信息时，视觉层级要低于正文。
- AI 面板支持历史记录折叠区，展示最近的多轮生成记录。
- 空状态使用中文提示，不使用冷冰冰的默认后台语气。

### 6.3 知识库

知识库是素材和设定管理区域，应使用卡片化结构：

- 搜索入口（带搜索图标、placeholder、快捷键提示 ⌘K）。
- 标签和分类筛选器（支持选中态高亮）。
- Markdown 文档预览卡片（带 Frontmatter 元信息头部：title、tags、updated）。
- 文档类型与更新时间。
- 引用到 AI 上下文的入口。
- 导入文件的拖拽区域设计（支持 .md、.markdown，自动解析 Frontmatter）。
- 空导入、搜索无结果等状态。

MVP 阶段未接真实数据时，也应保持符合整体风格的空状态。

### 6.4 人物与关系

人物与关系页用于管理角色、势力、关系线和出场约束。

推荐三栏结构：

- 左栏：人物搜索、主角/配角/势力筛选、人物列表。
- 中栏：人物详情，包括身份、目标、秘密、外貌锚点、口癖、当前状态、出场约束。
- 右栏：关系图、关系强度、关系变化记录、关联事件。

要求：

- 关系图要服务写作判断，不做复杂炫技可视化。
- 人物卡片要突出“当前状态”和“出场约束”，避免长篇角色设定失控。
- 可提供关系聚焦、空状态和角色详情等视图。

### 6.5 记忆与一致性

记忆与一致性页用于管理章节摘要、硬约束、人物状态和冲突审查。

推荐三栏结构：

- 左栏：记忆层级筛选：短期记忆、章节摘要、硬约束、人物状态、时间线。
- 中栏：记忆条目列表，包含来源章节、更新时间、是否注入 Prompt、待确认状态。
- 右栏：一致性审查，包含冲突严重程度、证据片段、修复建议。

关键文案约束：一致性审查必须表现为“AI 辅助建议，需作者确认后生效”，不要暗示自动修复或自动判定绝对正确。

### 6.6 AI 导演 / AI 生成面板

AI 是创作助手，不是控制台。

要求：

- 表单字段分组清楚。
- 支持续写、润色、改写、提纲、伏笔回收等意图。
- 重要控制项包括 POV、出场人物、禁用内容、风格样例、目标字数。
- 主生成按钮突出但不刺眼。
- 生成结果使用纸条或批注样式。
- 生成中状态要明确，生成失败要可恢复。
- 错误提示可理解，避免技术堆栈直出给用户。

### 6.7 导出

导出页用于把本地创作内容整理为可交付文件。

要求：

- 支持 Markdown、TXT、章节包等导出方向。
- 显示导出范围、章节数量、字数、目标目录。
- 导出前检查缺失章节、未保存内容、非法路径等问题。
- 导出成功提示应包含输出位置和下一步操作。
- 页面标题与导航激活态必须是“导出”，不要误用“设置”。

### 6.8 设置

设置页承载低频配置，不应压过创作入口。

应包含：

- 本机目录校验。
- AI Provider 配置。
- 主题偏好。
- 减少动效。
- 缓存与模型目录说明。

危险操作需二次确认，并与普通设置项保持视觉距离。

## 7. 组件规范

### 7.1 App Shell / Page Shell

- 侧栏使用暖色低对比背景。
- 当前导航项使用柔和高亮，不用强蓝色。
- Header 轻薄，可使用半透明纸面效果。
- Page Shell 应统一侧栏、Header、页面标题和主体区域宽度。

### 7.2 Panel / Card

- 使用纸面背景、统一圆角、轻阴影。
- 边框只用于辅助层级，不做强分割线。
- 卡片标题要简洁，中文优先。
- 高密度卡片中优先使用区块标题和状态胶囊，不堆叠重按钮。

### 7.3 Button

- 主按钮使用金棕色。
- 次按钮使用纸面色 + 轻边框。
- 悬停时只轻微加深，不使用高饱和色。
- 禁用态保持可辨认。
- 高风险操作不要复用主按钮样式。

### 7.4 Input / Textarea

- 背景使用 `--color-paper-soft`。
- 聚焦态使用金棕色外圈或边框。
- 长文本输入使用舒适行高。
- Placeholder 使用低对比棕灰。
- 搜索框、筛选框、正文输入的视觉权重应区分。

### 7.5 Menu / List / Tree

- 列表项高度不低于 40px。
- 当前项使用柔和纸签效果。
- 悬停态不改变布局尺寸。
- 树结构要保证层级缩进清晰，章节标题过长时可换行或截断并保留完整标题查看方式。

### 7.6 Icon / Status Pill

- 图标与中文标签组合使用，避免纯图标导航。
- 同一组图标线宽、尺寸和颜色保持一致。
- 状态胶囊用于保存成功、生成中、待确认、冲突、已导出等轻量状态。
- 状态不能只依赖颜色，需配合文字或图标。

### 7.7 Empty / Loading / Alert

- 空状态文字要像产品提示，而不是错误。
- Loading 不应遮挡整个写作区太久。
- Alert 使用柔和背景，不使用刺眼大红/大绿。
- 可恢复错误应给出下一步动作，如重试、检查目录、返回工作台。

### 7.8 Toast / Notification

- 轻量通知条，顶部居中或右下角出现。
- 成功、错误、警告、信息四种变体，对应不同图标和边框色。
- 带可选关闭按钮，自动消失或手动关闭。
- 使用 `--shadow-floating` 阴影，不抢夺主编辑区注意力。

### 7.9 Modal / Dialog

- 覆盖层背景使用半透明深棕 + backdrop blur。
- 对话框使用纸面色、面板圆角、主面板阴影。
- 确认对话框：标题 + 内容 + 主次按钮。
- 危险操作对话框：红色主按钮 + 明确二次确认文案。

### 7.10 Skeleton / 加载骨架屏

- 文本行骨架：圆角矩形占位，使用 `--color-paper-strong` 填充。
- 卡片骨架：带标题行 + 多行内容占位。
- 列表项骨架：头像占位 + 标题/副标题两行占位。
- 用于内容加载前的过渡，避免整页空白。

### 7.11 Dropdown Menu

- 圆角 14px，纸面色背景，`--shadow-floating` 阴影。
- 菜单项高度 40px，含图标 + 文字组合。
- 支持选中态（`--color-paper-strong` 填充）、禁用态（文字变淡）、分隔线。

### 7.12 Segmented Control

- 分段控制器用于同层级选项切换（如视图切换、排序方式）。
- 背景使用 `--color-paper-soft`，选中项使用 `--color-paper-strong`。
- 圆角统一，选项之间留 4px 间隙。

## 8. 可访问性

- 正文和背景对比度必须足够，不能为了羊皮纸效果牺牲可读性。
- 所有可点击元素都要有可见焦点态。
- 表单输入必须保留清晰 label 或 placeholder。
- 不依赖颜色作为唯一状态表达。
- 支持键盘 Tab 顺序自然移动。
- 动效不应影响用户输入。
- 页面缩窄时优先保持主编辑和主要内容可读，再折叠辅助面板。

## 9. 依赖约束

本阶段避免新增大型依赖。

不新增：

- 新 UI 组件库。
- Tailwind / UnoCSS 等原子 CSS 框架。
- 动画库。
- 图标大包。
- 外部字体包。
- 大型富文本编辑器。
- 重型关系图或流程图可视化库。

Element Plus 使用策略：

- 短期保留，避免破坏已完成业务闭环。
- 通过全局 CSS 变量和覆盖样式统一视觉。
- 后续逐步按需导入或替换简单布局组件。

Markdown 编辑器使用策略：

- 当前代码仍以 textarea 保证本地章节闭环。
- 如果近期要做正式 Markdown 编辑器，再评估 CodeMirror / Milkdown / TipTap Markdown。
- 不应在 UI 美化阶段额外接入大型编辑器依赖。

知识库依赖使用策略：

- `gray-matter`、`markdown-it`、`sanitize-html`、`minisearch` 与知识库和 Markdown 预览相关。
- 在知识库功能真正接入前，不扩大它们的使用面。

## 10. 验收标准

- 页面主体语言为中文。
- 首页、工作台、知识库、人物与关系、记忆与一致性、AI、导出、设置的导航和标题一致。
- 整体风格偏暖黄色 / 羊皮纸，但不过度拟物。
- 主编辑区比侧栏和 AI 面板更突出。
- 所有交互控件有可见悬停、聚焦、禁用和加载状态。
- 图标覆盖主要导航、写作章节、知识检索、人物关系、记忆一致性、AI 生成、状态反馈、导出设置等场景。
- 工作台原有本地数据闭环不被破坏。
- 一致性审查等 AI 判断必须需要作者确认后生效。
- 不因 UI 改造引入新的大型依赖。
